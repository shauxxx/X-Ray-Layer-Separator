# PCB Layer Separation: стек технологий

Язык: **Python 3.10+**.

## Ядро и обработка данных

| Библиотека | Для чего |
|---|---|
| `numpy` | основа: массивы проекций и срезов |
| `scipy` | фильтры, интерполяция, геометрические преобразования |
| `numba` | ускорение shift-and-add и обратной проекции |
| `imageio` / `tifffile` | чтение 16-битных PNG, запись стеков TIFF |
| `pydantic` или `dataclasses` | модель `ScanConfig` для параметров из лога |

## Обработка изображений и реконструкция

| Библиотека | Для чего |
|---|---|
| `scikit-image` | фильтры, сегментация, FBP/SART (`skimage.transform`) |
| `opencv-python` | регистрация проекций, морфология, контуры |
| `astra-toolbox` (опционально) | продвинутая и GPU-реконструкция, если подойдёт геометрия установки |

## Интерфейс

| Инструмент | Для чего |
|---|---|
| `argparse` или `typer` | CLI (`pcblayers reconstruct ...`) |
| `streamlit` или `PyQt6` | просмотрщик слоёв (выбрать один) |
| `matplotlib` | графики и визуальная проверка |

## Качество кода и инфраструктура

| Инструмент | Для чего |
|---|---|
| `pytest` | тесты, в том числе на синтетических данных |
| `ruff` | линтер и форматирование |
| `pre-commit` | автоматические проверки перед коммитом |
| GitHub Actions | CI: тесты и линтер на каждый pull request |
| `pyproject.toml` | зависимости и сборка пакета |

## Рекомендации

- Один виртуальный менеджер окружения на всех (`venv` или `uv`), зависимости фиксируются в `pyproject.toml`.
- `.gitignore` шаблон Python, плюс `data/` и `*.tif`, чтобы снимки не попали в репозиторий.
- Для стартовой версии достаточно `numpy`, `scipy`, `scikit-image`, `opencv-python`, `imageio`, `pytest`. `numba`, `astra-toolbox` и GUI подключаем по мере необходимости.
