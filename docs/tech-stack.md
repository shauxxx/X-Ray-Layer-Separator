# PCB Layer Separation: стек технологий

Язык: **Python 3.10+**.

## Библиотеки по задачам

| Библиотека | Для чего | Кто использует |
|---|---|---|
| `Pillow` | чтение GIF, извлечение кадров, сохранение PNG | участники 1, 3 |
| `numpy` | основа: кадры как массивы, все вычисления | все |
| `opencv-python` | фазовая корреляция, оптический поток, выравнивание кадров, морфология | участники 1, 2, 3 |
| `scipy` | фильтры, интерполяция, оптимизация | участники 2, 3 |
| `scikit-image` | `phase_cross_correlation` (субпиксельные смещения), шумоподавление, метрики сходства (SSIM, PSNR) | участники 2, 3, 4 |
| `matplotlib` | график смещений, визуальное сравнение результата с кадрами | участники 2, 4 |
| `pytest` | тесты, в том числе на синтетических данных | участник 4 и все |
| `argparse` или `typer` | запуск из командной строки | участник 4 |
| `ruff` | линтер и форматирование | все |

## Распределение по участникам

| Участник | Основные инструменты |
|---|---|
| 1. Загрузка и подготовка GIF | `Pillow`, `numpy`, `opencv-python` |
| 2. Анализ движения | `opencv-python`, `scikit-image`, `scipy`, `matplotlib` |
| 3. Разделение и реконструкция | `numpy`, `scipy`, `scikit-image`, `opencv-python` |
| 4. Интеграция и тестирование | `pytest`, `argparse`/`typer`, `scikit-image` (метрики), `matplotlib` |

## Рекомендации

- Минимальный набор для старта: `Pillow`, `numpy`, `opencv-python`, `scipy`, `scikit-image`, `matplotlib`, `pytest`. Остальное подключаем по мере необходимости.
- Версии зависимостей фиксируем в `pyproject.toml` и описываем установку в README одной командой.
- `.gitignore` по шаблону Python, плюс `output/` и большие GIF и снимки, чтобы они не попали в репозиторий.
- Единый формат кадров между модулями (например, `float32`, диапазон 0..1, один канал) задаём в первый же день, это самое частое место, где модули не стыкуются.
